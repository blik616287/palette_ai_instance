## Pass 2 — everything else

Each finding below names the files touched. All changes carry the inline review reference.

### 🔴 C2 — `SDKInstaller.Uninstall` discards `context.Context`

`internal/helm/installer.go`, `internal/cleaner/cleaner.go`

- `Uninstall` now takes a named `ctx` and checks `ctx.Err()` at entry and again right before invoking `action.Uninstall.Run` (which itself has no ctx parameter — helm SDK limitation).
- `cleaner.runHelmUninstalls` checks `ctx.Err()` between each release in the plan.
- Net effect: a SIGINT during a multi-release teardown aborts at the next release boundary instead of running every release to completion.
- Test: `TestCleanup_CancelledContextStopsBetweenReleases`.

### 🔴 C3 — Duplicate `error:` printed on early failures

`internal/cli/deploy.go`, `internal/cli/cleanup.go`

- Removed the four `fmt.Fprintln(errOut, "error:", err)` calls in the CLI runners. `main.go` is now the single stderr sink (cobra already has `SilenceErrors: true`).
- **Verified live:** `deploy --config /does/not/exist.yaml` now prints exactly one `error:` line (was two).

### 🟠 H1 — `WaitForPodsReady` hangs on terminal Hook-Job pods

`internal/kube/client.go`

- `isPodReady` now treats `PodSucceeded` / `PodFailed` phase as ready. Helm pre/post-install Hook Jobs leave behind Succeeded pods with no `PodReady=True` condition; the old logic counted them as not-ready forever, wedging `--validate`.
- Tests: `TestWaitForPodsReady_TerminalPodsCountAsReady`, `…_FailedPodCountsAsReady`; the old `…_PodWithoutPodReadyConditionIsNotReady` was renamed/retargeted to the *pending* case.

### 🟠 H2 — `--level full` silently force-finalized stuck namespaces

`internal/cleaner/cleaner.go`, `internal/cli/cleanup.go`

- Force-finalize (`spec.finalizers` clear via `/finalize`) is now **opt-in** for `--level full` via the new `--force-finalize-stuck` flag, and remains automatic for `--level reset`.
- Without the flag, a stuck namespace returns a clear error pointing at the flag.
- Default `--namespace-wait` bumped 3m → **10m** (real clusters routinely take 5–8m to drain finalized resources).
- Tests: `TestCleanup_LevelFull_StuckNamespaceErrorsWithoutForceFlag`, `…_ForceFinalizeOptIn`, `TestCleanup_LevelReset_ForceFinalizesImplicitly`.

### 🟠 H3 — `DisableHooks` hardcoded for all releases

`internal/helm/helm.go`, `internal/helm/installer.go`, `internal/cleaner/cleaner.go`

## Path notes (lessons for future passes)

From Pass 1 (dependency bumps):

- **helm v3.18.5 forces Go 1.24+** — the helm bump compels the Go bump.
- **Docker Hub anonymous rate limit (100/6h/IP)** blocks tag-matrix probing mid-bump — AWS ECR mirror (`public.ecr.aws/docker/library/...`) has no such limit.
- **Go 1.21+ auto-normalizes the `go X.Y` directive** to `go X.Y.0` when the toolchain is newer — strict 2-component compare scripts break.
- **Tag matrix is sparse for new Go patches** — a new `Go X.Y.Z` is typically published only against the current Alpine; Go + Alpine bumps often have to move together.
- **`// indirect` deps can still be reachable** — `govulncheck` does real callgraph analysis; pin the version in your own `go.mod` to fix.
- **golangci-lint must stay within ~1 minor of the toolchain** — `v1.61.0` emitted spurious `undefined` typecheck errors against a Go 1.24+ module tree.

From Pass 2 (findings):

- **Tightening a silent-default into a hard error breaks tests that relied on the default** — M8's `HelmTimeout > 0` enforcement broke 10 deployer tests that never set the field. Budget for the test fan-out when removing a permissive fallback.
- **Parallelizing production code forces test-fake synchronization** — L6's parallel namespace deletes meant the test `fakeKube` needed a mutex or `-race` trips. Any time you add concurrency, audit the fakes.
- **A YAML-AST post-renderer reformats the whole stream** — unlike surgical regex edits, an AST decode/re-encode touches every manifest. yaml.v3 Node mode is semantically faithful (preserves comments/order/styles), but it's a wider blast radius; weigh it for post-renderers specifically.
- **Enabling new linters surfaces real bugs** — `gocritic`'s `exitAfterDefer` caught a genuine `os.Exit`-bypasses-`defer` issue in `main.go`. Budget a fix-up round when expanding the linter set.
- **An empty yaml.v3 Encoder errors on `Close()`** — decode all documents first, return early for the empty-stream case before constructing the encoder.
